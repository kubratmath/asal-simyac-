# asal-simyac-
Kozmik Asal Reaktörü, düşen bileşik sayıları yalnızca asal lazerlerle parçalayarak canlı çarpan ağacı ve bölen listesi inşa ettiğiniz stratejik bir matematik oyunudur. Bölünemeyen asal taşlara ateş edildiğinde açılan tehlikeli asal karadelikleri durdurmak için doğru anda Asal Mühür kullanarak canınızı korumanız ve reaktörü dengede tutmanız gerekir.
